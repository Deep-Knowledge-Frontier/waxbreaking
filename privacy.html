이 앱은 무엇입니까

wax-uploader는 WaxBreaking 유튜브 채널 운영자가 자기 채널에 영상을 올리기 위해 직접 만든 개인용 도구입니다. 일반에 배포하거나 다른 사용자에게 제공하지 않습니다.

수집하는 정보

이 앱은 어떤 개인정보도 수집하지 않습니다.

  • 이용자 데이터베이스가 없습니다.
  • 분석 도구, 추적 스크립트, 쿠키를 사용하지 않습니다.
  • 제3자에게 어떤 정보도 전달하거나 판매하지 않습니다.

구글 계정 접근 권한

이 앱은 YouTube Data API v3를 통해 운영자 본인 계정의 다음 권한만 사용합니다.

  • youtube.upload — 본인 채널에 영상 업로드
  • youtube — 업로드한 영상의 제목·설명·썸네일 설정

인증 토큰은 운영자의 개인 컴퓨터에만 저장되며 외부로 전송되지 않습니다. 권한은 구글 계정 권한 관리에서 언제든 철회할 수 있습니다.

구글 API 서비스 이용자 데이터 정책

이 앱의 구글 API 정보 사용은 Google API Services User Data Policy를 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.

문의

이 방침에 대한 문의는 유튜브 @WaxBreaking 채널을 통해 주시기 바랍니다.

English summary. wax-uploader is a personal tool used by the owner of the WaxBreaking YouTube channel to upload videos to their own channel. It collects no personal data, uses no analytics or cookies, and shares nothing with third parties. It accesses only the owner's own Google account through the YouTube Data API. Tokens are stored locally. Use of Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
